Tentang Projek Ini

Halaman ini dibuat sebagai contoh navigasi antar halaman pada website sederhana.

Tujuan Sandbox

Website ini dirancang untuk menguji komponen dasar pemrograman web seperti struktur HTML, styling CSS, dan alur navigasi antarhalaman tanpa ketergantungan pada *framework* eksternal.

Teknologi yang Digunakan

  • HTML5: Elemen semantik (header, nav, main, section, footer).
  • CSS3: Flexbox, CSS Grid, Media Queries, dan efek hover.
